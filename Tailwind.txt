🛠️ Tailwindの基本ルール（略語の法則）
まずはこのアルファベットの意味を知るだけで、クラス名が暗号じゃなくて「英語の略」に見えてくるよ！
p = padding（内側の余白）
m = margin（外側の余白）
bg = bground（背景色）
text = 文字の色や大きさ
w / h = width（幅） / height（高さ）

数字のルール: 1 が 0.25rem（約4px）。だから p-4 なら 4×4=16px の余白になる！

1. 余白（スペース）系
要素と要素の隙間を空けるときの必須コンビ。

クラス名	意味・効果	覚え方
p-4 / p-6	上下左右の内側余白を空ける	padding
px-4	左右（x軸）だけに余白を空ける	padding x
py-4	上下（y軸）だけに余白を空ける	padding y
mb-4	下側（bottom）に外側余白を空ける	margin bottom
mx-auto	左右のマージンを自動（auto）にして中央揃えにする	margin x auto
space-y-4	リストや並んだ要素の「縦方向の隙間」を一括で空ける	space y

2. レイアウト・並び方系
要素を横並びにしたり、位置を整えたりするときに使う。

クラス名	意味・効果
flex	要素を横並び（フレックスボックス）にする
flex-col	要素を縦並びにする
items-center	縦方向の中央に揃える
justify-between	左右の端にパカーッと離して配置する
gap-4	フレックスやグリッドの要素同士の隙間を空ける

3. 見た目・デザイン系
カードっぽいデザインを作ったり、色をつけたりする。

クラス名	意味・効果
bg-white / bg-gray-100	背景色を変える（bg = background）
text-black / text-gray-500	文字の色を変える
font-bold	文字を太字にする
text-lg / text-xl / text-2xl	文字を大きくする（サイズが上がっていく）
rounded / rounded-lg / rounded-full	角を丸くする（rounded）。full だと真円になる
border / border-gray-200	枠線をつける
shadow-md	影（ドロップシャドウ）をつける


4. サイズ・表示系
要素の大きさを制限したり決めたりする。

クラス名	意味・効果
w-full	横幅を親要素いっぱいに広げる（100%）
max-w-2xl	横幅の最大値を制限する（広がりすぎないようにする）
h-screen	高さをスマホやPCの画面いっぱいに合わせる

5. ボタン関連
shadow-md：うっすら影をつけて、画面から浮き上がっている立体感を出す。
hover:bg-blue-700：マウスを乗せたときに、少し濃い青に変えて「触れるんだよ」と教える。
active:scale-95：ポチッとクリックした瞬間に少し縮むことで、押した感触（フィードバック）を出す。
transition-all duration-200：色の変化や縮む動きを、カクカクさせずに滑らかにアニメーションさせる。
